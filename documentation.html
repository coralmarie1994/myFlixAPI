API Documentation

Introduction

This API allows you to register a user profile to access movie information, create a favorite list, and manage user data.


Users API Endpoints

Get User Information

Method: GET

URL: /users

Description: Retrieve information about all users.

Response:
200 OK: Array of user objects
500 Internal Error: Something's Gone Wrong

Get Single User Information

Method: GET

URL: /users/:Username

ParameterName: of username to retrieve

Description: Retrieve information about single user by username.

Response:
200 OK: Array of user object
404 Not Found: User not found.
500 Internal Error: Something's gone wrong

Create/Register a User

Method: POST

URL: /users

Body (JSON)
{"Username":"Name",
"Password": "Password",
"Email": "email@example.com",
"Birthday": "1994-11-11"}

Description: Create a new user with Username, Password, Email & Birthdate.

Response:
201 Created: New created user object
400 Bad Request: Username already exists
500 Internal Error: Something's gone wrong

Update User

Method: PUT

URL: /users/:Username

Body (JSON)
{"Username":"newUsername",
"Password": "newPassword",
"Email": "newEmail@example.com",
"Birthday": "1994-11-11"}

Description: Update an existing user with new Username, Password, Email & Birthdate.

Response:
200 OK: Updated user object
404 Not Found: User not found
500 Internal Error: Something's gone wrong

Update User

Method: POST

URL: /users/:e/Movies/:MovieID

Parameters:
Username: of user wanting to modify
MovieID: The Object ID for movie to be added to favorites

Description: Adds a movie objectId to users favorite array list.

Response:
200 OK: Updated user object
500 Internal Error: Something's gone wrong

Remove Movie from Favorites

Method: DELETE

URL: /users/:Username/Movies/:MovieID

Parameters:
Username: of user wanting to modify
MovieID: The Object ID for movie to remove from favorites

Description: Adds a movie objectId to users favorite array list.

Response:
200 OK: Success message
404 Not Found: User or movie not found
500 Internal Error: Something's gone wrong

Delete User

Method: DELETE

URL: /users/:Username

Parameters:
Username: of user to be deleted

Description: Deletes a user from the database.

Response:
200 OK: Success message
404 Not Found: User not found
500 Internal Error: Something's gone wrong


Movies API Endpoints

Get All Movies

Method: GET

URL: /movies

Description: Retrieve information about all movies on API database.

Response:
200 OK: Array of movie documents
500 Internal Error: Something's gone wrong

Get Movie by Title

Method: GET

URL: /movies/:Title

ParameterTitle: of movie to retreive

Description: Retrieve information about single movie title.

Response:
200 OK: Array of matching movie object
404 Not Found: Movie not found
500 Internal Error: Something's gone wrong

Get Movie Genre

Method: GET

URL: /genre/:Name

ParameterName: of genre to retreive

Description: Retrieve information about genre by name.

Response:
200 OK: The genre description
404 Not Found: Movie not found
500 Internal Error: Something's gone wrong

Get Director

Method: GET

URL: /directors/:Name

ParameterName: of director to retreive

Description: Retrieve information about director by name.

Response:
200 OK: The directors (bio, birth, death)
404 Not Found: Movie not found
500 Internal Error: Something's gone wrong
