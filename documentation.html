API Documentation

Introduction

This API allows you to register a user profile to access movie information, create a favorites list, and manage user data.

Users API Endpoints

Get All Users

Method: GET

URL: /users

Description: Retrieve information about all users.

Response:
200 OK: Array of user objects
500 Internal Error: Something went wrong

Get Single User Information

Method: GET

URL: /users/:Username

Parameter: Username to retrieve

Description: Retrieve information about a single user by username.

Response:
200 OK: User object
404 Not Found: User not found
500 Internal Error: Something went wrong

Create/Register a User

Method: POST

URL: /users

Body (JSON):
{"Username":"Name", "Password": "Password", "Email": "email@example.com", "Birthday": "1994-11-11"}

Description: Create a new user with Username, Password, Email, and Birthdate.

Response:
201 Created: New user object
400 Bad Request: Username already exists
500 Internal Error: Something went wrong

Update User

Method: PUT

URL: /users/:Username

Body (JSON):
{"Username":"newUsername", "Password": "newPassword", "Email": "newEmail@example.com", "Birthday": "1994-11-11"}

Description: Update an existing user's information.

Response:
200 OK: Updated user object
404 Not Found: User not found
500 Internal Error: Something went wrong

Add Movie to Favorites

Method: POST

URL: /users/:Username/Movies/:MovieID

Parameters:
Username: The user
MovieID: The ObjectId of the movie to add

Description: Add a movie to the user's list of favorite movies.

Response:
200 OK: Updated user object
500 Internal Error: Something went wrong

Remove Movie from Favorites

Method: DELETE

URL: /users/:Username/Movies/:MovieID

Parameters:
Username: The user
MovieID: The ObjectId of the movie to remove

Description: Remove a movie from the user's list of favorite movies.

Response:
200 OK: Success message
404 Not Found: User or movie not found
500 Internal Error: Something went wrong

Delete User

Method: DELETE

URL: /users/:Username

Parameters:
Username: The user to delete

Description: Delete a user from the database.

Response:
200 OK: Success message
404 Not Found: User not found
500 Internal Error: Something went wrong

Login

Method: POST

URL: /login

Parameters:

Username: The username of the user to login
Password: The password of the user to login

Description: Authenticates a user with the provided username and password. If successful, returns a JSON Web Token (JWT) for authenticated requests.

Response:
200 OK: Returns a JSON object containing the user data and JWT token.
400 Bad Request: Invalid username or password, or authentication failure.
500 Internal Server Error: An unexpected error occurred during the login process.

Movies API Endpoints

Get All Movies

Method: GET

URL: /movies

Description: Retrieve all movies in the database.

Response:
200 OK: Array of movie objects
500 Internal Error: Something went wrong

Get Movie by Title

Method: GET

URL: /movies/:Title

Parameter: Title of the movie to retrieve

Description: Retrieve details of a specific movie by title.

Response:
200 OK: Movie object
404 Not Found: Movie not found
500 Internal Error: Something went wrong

Get Genre Info

Method: GET

URL: /genre/:Name

Parameter: Name of the genre

Description: Retrieve genre details by name.

Response:
200 OK: Genre object
404 Not Found: Genre not found
500 Internal Error: Something went wrong

Get Director Info

Method: GET

URL: /directors/:Name

Parameter: Name of the director

Description: Retrieve director information by name.

Response:
200 OK: Director object
404 Not Found: Director not found
500 Internal Error: Something went wrong
